# 🌍 Deploy Using GitHub Pages

This portfolio can be hosted as a static website using GitHub Pages.

### Step 1

Push the project to GitHub:

```bash
git init
git add .
git commit -m "Initial portfolio website"
git branch -M main
git remote add origin https://github.com/manimaran-p-g/aws-devops-portfolio.git
git push -u origin main
```

### Step 2

Go to:

```text
GitHub Repository
→ Settings
→ Pages
```

### Step 3

Under **Build and deployment**, select:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

### Step 4

Save the configuration.

GitHub will generate a public URL for the portfolio.
